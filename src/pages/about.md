# About / プロフィール

kuroneko52（@kuroneko52）。フルスタックソフトウェアエンジニア。

活動の要旨:
- クライアントアプリケーション（フロントエンド）とサーバーサイドの設計・実装を行います。
- OS（Linux 等）とミドルウェア（Apache、PHP、MariaDB など）を含めたデプロイと運用の実務も扱います。
- CI/CD・ワークフロー自動化やエッジ配信（Cloudflare Pages など）の導入も経験があります。

主要技術スタック（リポジトリと実務の両面を反映）:
- 言語: JavaScript / TypeScript
- ランタイム / フレームワーク: Node.js (engines: >=22.12.0), Astro (v7.x)
- コンテンツ: Markdown / MDX（@astrojs/mdx を使用）
- 画像処理: sharp（サムネイル等のビルド処理）
- 配信 / ホスティング: Cloudflare Pages（エッジ配信）
- 静的サイト機能: RSS（@astrojs/rss）、サイトマップ（@astrojs/sitemap）
- バージョン管理 / CI: Git / GitHub（Actions 等のワークフロー運用を想定）
- OS / ミドルウェア運用: Linux、Apache、PHP、MariaDB（LAMP 系の構築と運用経験）
- 型定義 / 設定: TypeScript（tsconfig.json を利用）

現在のプロジェクトについて:
- このリポジトリは Astro のブログスターターをベースにしており、src/content/blog/ に Markdown/MDX 記事を置いて公開します。
- package.json に記載の依存関係（astro, @astrojs/mdx, @astrojs/rss, @astrojs/sitemap, sharp）をビルドで利用しています。

目的:
- kuroneko52-blog は開発ログと実装メモの公開場所です。プロダクト設計・実装・運用の記録を残しています。
- 最終的にはエンタープライズ級のサービス設計とローンチを目指しています。
